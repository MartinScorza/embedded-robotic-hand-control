# Third-party notices

## Texas Instruments

The DFRobot Code Composer Studio project originated from the Texas Instruments SimpleLink MSP432P4 SDK BOOSTXL-EDUMKII joystick example.

This public-safe tree retains the Crystalfontz/ST7735 LCD support files used by the project. Their original Texas Instruments BSD-style license notices are preserved in the source files.

MSP432 startup, system and linker support that existed as copies in the original academic workspace is not duplicated here; a reproducible build should obtain those components from the declared TI SDK/toolchain.

The Texas Instruments name must not be used to endorse derived products without permission.

## UTC assets / internal interface documentation

The original academic project referenced internal UTC technical documentation for the robotic-hand interface board. That internal document is not included in this public-safe repository.

Board-specific source that could disclose the internal register map or interface details is also withheld pending confirmation of redistribution rights and provenance.

## Branding

The original Python GUI included a UTC logo image. The logo is not included in this public-safe repository. The existing GUI code already falls back to a text label when the image is absent.
